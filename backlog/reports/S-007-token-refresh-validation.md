# S-007 — Обновление токена методиста

Дата: 28 октября 2026. База: production, 347e586.

## Реализация

Общий клиент API повторяет авторизованный запрос после 401 один раз, предварительно вызывая существующий POST /auth/refresh. Параллельные запросы разделяют одно обновление. Оба ротированных токена сохраняются в sessionStorage и передаются подписчикам состояния React. Поздние ответы и обновления профиля не возвращают предыдущие токены. Обновление credentials не запускает повторную загрузку начальных данных; изменение пользователя/музея по-прежнему запускает её.

Обычный 403, public auth endpoints, logout и mock-сессии не запускают refresh. Ответ 401/403 на refresh завершает сессию; сеть, 5xx и некорректный успешный ответ сохраняют её для повторной попытки. При выходе локальная сессия очищается сразу; запоздалый refresh не восстанавливает её. Успешный refresh не меняет тело и X-Museum-ID повторяемого запроса, включая FormData и бинарную загрузку QR.

- Параллельные запросы, поздний 401, отозванный refresh, повторный 401, сеть/503, невалидный ответ, выход/смена аккаунта/смена музея во время обновления, FormData, QR и сохранение свежих credentials при позднем ответе профиля покрыты тестами клиента.

## Ограничения

Браузерная проверка использовала локальную тестовую службу: виджеты, не относящиеся к авторизации, преднамеренно отвечали 503. Это не проверка бизнес-данных музея. Реальный пользовательский аккаунт и production-токены не читались. Уже удалённую сессию восстановить невозможно: потребуется один повторный вход. Сроки жизни access/refresh token, серверная политика, visitor и landing не изменены.

Результат штатной публикации production и серверных HTTPS-проверок фиксируется в GitHub Actions и итоговом сообщении.
