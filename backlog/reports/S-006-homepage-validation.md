# S-006 — Проверка главной страницы

Дата: 28 октября 2026. База: production, 19e6b6c.

## Изменения

Ясное предложение музейных маршрутов в браузере; входы /methodist/ и /visitor/; рабочие заявки вместо листа ожидания и пустых разделов; три сценария применения, объяснение двух панелей и начала работы; метаданные и noscript fallback. Содержимое диалога сохраняется во время анимации закрытия.

## Подтверждено локально

- npm test: 8 из 8 тестов контракта заявок проходят.
- npm run build: TypeScript и производственная статическая сборка проходят.
- npm run lint: без замечаний (проверка исполнителя).
- React Doctor: --scope changed --base origin/production --no-telemetry, замечаний нет. Сравнение с main некорректно для этой задачи: main не содержит Landing.
- Браузер: ширины 320, 768, 1024, 1440 CSS px — document.scrollWidth соответствует ширине; горизонтальное переполнение не обнаружено.
- Внутренние якоря существуют; изображения загружаются; одна h1; ссылки на обе панели имеют соответствующие подписи.
- Мобильное меню открывается; Escape закрывает его и возвращает фокус на кнопку.
- Форма открывается; пустая отправка показывает валидацию, aria-invalid и фокус e-mail. Escape закрывает диалог и возвращает фокус на CTA.
- Годовой тариф показывает 7 492,50 ₽/месяц и 89 910 ₽ за год; исходные суммы и состав тарифов сохранены.
- Кнопка «Все вопросы» открывает 10 ответов.
- В отдельной вкладке финальной производственной сборки после открытия/закрытия диалога ошибок консоли нет.
- Backend, обе панели, зависимости и сценарий публикации не изменены.

## Ограничения проверки

Не отправлялось реальное письмо; SMTP не проверялся сквозным тестом. Авторизованные сценарии панелей не проверялись. Живой опубликованный демомаршрут и настоящие скриншоты кабинета не предоставлены: на странице переходы в панели и явно обозначенные иллюстрации. Масштаб браузера 200% и программа экранного доступа отдельно не проверялись. Существующие тарифные обещания сохранены без новой продуктовой валидации.

Результат публикации фиксируется в GitHub Actions и итоговом сообщении: push в production запускает штатный Deploy to Selectel. До завершения этого процесса серверную версию нельзя считать обновлённой.
