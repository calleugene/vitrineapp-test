# S-012 — Проверка скрытия ручного ввода

Дата: 29.10.2026.

## Реализовано

Удалены форма ручного ввода, её действие и точки входа на странице музея и в сканере. Подсказки ошибок камеры/QR предлагают повторную попытку или системную камеру телефона. Существующие переходы без publicCode, QR с artifactId и /a/{artifactId} используют существующий ArtifactFoundView; неизвестная старая ссылка показывает notFound. Публичные коды/API и iframe не изменены.

## Доказательства

- Visitor `npm run check`: PASS (lint, typecheck, smoke flow, real museum catalogue, production build).
- `git diff --check`: PASS.
- В исходниках панели больше нет SecretCodeView, enterSecretCode, ссылок на view secretCode и текстов «Ввести код» / «Введите код».
- React Doctor: 51/100, два предупреждения в ранее существующем EmbedArtifact.jsx (effect загрузки и обновление состояния после await); в файлах S-012 диагностик нет. Проверка сравнивает ветку с origin/main, поэтому охватывает и прошлые изменения.

## Ограничения

Аппаратное сканирование реальной камерой в этой задаче не проверялось. Серверные данные, publicCode и старые вспомогательные функции поиска по коду не удалялись.
