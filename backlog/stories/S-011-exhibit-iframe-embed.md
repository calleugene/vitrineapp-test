# S-011 — iframe опубликованного экспоната

Дата: 29 октября 2026. Основание — запрос пользователя на реализацию согласованной функции. Исполнитель: Go + Frontend в текущем чате. Статус: **реализовано и проверено локально; на production не опубликовано**.

Продуктовые правила и критерии: [основная история](../../../backlog/stories/S-011-exhibit-iframe-embed.md), [D-005](../../../docs/Product/DECISIONS.md). Отчёт: [S-011 validation](../reports/S-011-exhibit-iframe-validation.md).

## Реализация

- Блок «Встроить на сайт» в публикации/результате экспоната: действительная опубликованная ссылка, preview, HTML, ручное копирование при отказе clipboard, высота 320–1200 px (по умолчанию 640), узкий/широкий контейнер, общий счётчик.
- Изолированный HTML/React entry iframe `/embed/exhibits/{code}`. Только существующие экраны, навигация, повтор истории, логотип и вторичная ссылка на основную главную. Коллекция, обратная связь, авторизация и поведенческие события не загружаются.
- Существующий public resolver выдаёт последний неизменяемый снимок с `Cache-Control: no-store`, включая недоступные состояния. Новый publish виден при перезагрузке; открытая история остаётся на загруженной версии. Архивирование/удаление закрывают последующий resolve. Restore следует существующему правилу сервиса: при наличии публикации возвращает публичную доступность прежнего снимка.
- Минимальный счётчик: пустой POST, суточный агрегат по artifact, защищённое чтение total в кабинете; без записей посетителей. `ARTIFACTS_EMBED_COUNTING_ENABLED=false` по умолчанию до проверки production data flow по D-004.
- Миграция 0007, правила nginx/Caddy, сборка отдельного embed.html и его проверка в пакете релиза. Автоматическая замена активной конфигурации nginx не выполняется.

## Выпуск

Применить и проверить актуальные правила reverse proxy, выполнить migration на PostgreSQL штатным запуском сервиса; проверить реальные HTTP headers. Отдельно проверить access/error/CDN logs и решение об обработке данных перед включением счётчика. Локальная проверка WordPress использует тестовую страницу/контент, а не сайт клиента.

## Уточнение оформления

По замечанию пользователя iframe использует тот же `StoryExperienceView` и stylesheet, что и основной просмотр экспоната. Отдельная упрощённая оболочка удалена. Адаптация ограничена высотой контейнера, разрешёнными действиями и подписью платформы; аналитика остаётся изолированной. Локальная WordPress-страница обновлена.

## Публикация и старые экспонаты — дополнительное поручение

Пользователь поручил добавить функцию на рабочий сайт и для старых экспонатов. Поддержаны 10-символьные коды миграции 0002 вместе с текущими 5-символьными; формат и снимки не меняются. Добавлен прямой пункт «Встроить на сайт» в меню каждой доступной опубликованной записи. В deploy включены идемпотентная установка nginx locations с backup/rollback и проверка существующих снимков/реальной PostgreSQL без повторной публикации.
