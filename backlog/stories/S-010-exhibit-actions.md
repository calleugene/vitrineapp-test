# S-010 — Экспонаты: действия и архив

Источник: прямое поручение пользователя от 29 октября 2026.

## Критерии

- Пользовательское название «Артефакты» заменить на «Экспонаты» во всей панели; технические идентификаторы и URL сохранить.
- В меню строки: Редактировать, Дублировать, Удалить, В архив. Для архивного экспоната вместо повторной архивации — Восстановить.
- Удаление требует модального подтверждения с названием, кнопками «Отмена» и «Да, удалить». Отмена не изменяет данные. Во время запроса повторное подтверждение блокируется, ошибка остаётся в модалке; успех удаляет строку.
- Архивные экспонаты — отдельный список «Экспонаты в архиве» ниже основного списка. Архивация/восстановление сохраняются на сервере и после перезагрузки.
- DELETE не подменяется архивированием: недоступность в кабинете, счётчиках и по публичному коду. Сохранять неизменяемые снимки D-002 внутренним логическим удалением; не удалять снимки опубликованных маршрутов. Миграция deleted_at без изменения существующих данных, API и tenancy.
- Проверки frontend lint/typecheck/tests/build, backend regression tests удаления, публичной недоступности, сохранения снимков, архива и восстановления. Публикация штатным процессом.
