# Онлайн-оплата подписки «Витрины»

В кабинете методиста музей выбирает оплачиваемый период и нажимает «Оплатить». Точка Банк открывает страницу эквайринга. После подтверждения банка «Витрина» применяет оплаченный период к музею. Администратор платформы видит все платежи и разбирает исключения, поэтому штатные оплаты проходят без ручного согласования.

В первой версии каждый период оплачивается отдельным платежом по кнопке. Руководитель, который работает в кабинете методиста как владелец своего музея, проходит тот же путь. Заказ сохраняет плательщика, музей, сумму, период и версию принятых условий.
