# ТЗ: «Сообщение музею»

21 октября 2026. Реализовано. Применяется к общей форме StoryFeedback во всех историях.

## Композиция

Светлый диалог шириной до 500px на затемнённом размытом фоне. Отступы 28px,
радиус 24px, заголовок 26px среднего начертания. Закрытие крестиком в правом
верхнем углу, область нажатия 44px. Под заголовком короткое объяснение.
Не использовать стандартные браузерные select и квадратные кнопки.

1. Переключатель «Отзыв / Вопрос / Идея», отображаемый как три сегмента.
   Значения API остаются review / question / suggestion.
2. Только для отзыва — пять звёзд с выбором оценки, без предвыбранной пятёрки.
   Выбранная оценка подписана словами; звёзды доступны клавиатурой.
3. Подписанное поле сообщения с контекстной подсказкой, счётчиком 0 / 5000,
   ограничением 5000 символов. Минимальная высота 120px.
4. Основная кнопка на всю ширину: «Отправить отзыв / вопрос / идею».
   Недоступна при пустом тексте, невыбранной оценке отзыва и во время запроса.
5. Примечание о модерации — только для отзыва. Требование авторизации
   объяснено до отправки. Ошибка не очищает данные.

## Поведение и доступность

- Отправлять существующий запрос и сохранять механизм request ID для повторов.
- Повторный клик во время запроса не создаёт новую отправку.
- Pending-состояние, понятная ошибка с повтором и отдельное подтверждение успеха.
- Для вопросов/идей не обещать срок ответа и не говорить о публикации отзыва.
- Черновик сохраняется при закрытии и повторном открытии в этой сессии просмотра.
- Диалог через портал поверх страницы, role=dialog, aria-modal, связанный
  заголовок/описание. Фокус внутри, Escape закрывает, после закрытия фокус
  возвращается на кнопку открытия. Не закрывать по случайному клику на фон.
- На 320px диалог помещается по ширине; на малой высоте содержимое прокручивается.
  Учесть safe-area, динамическую высоту окна, reduced-motion и видимый focus.
- Не отправлять реальные отзывы во время QA; использовать отдельный тестовый
  сценарий для проверки ответов сервера.

## Проверка

Проверить три типа, выбор звёзд мышью и клавиатурой, валидацию, смену типа,
сохранение черновика при закрытии, Escape/Tab, ошибку и успех, 320px и десктоп.
Выполнить lint, typecheck, smoke и build.

## Реализация и QA

Форма вынесена в StoryFeedback.jsx; используется существующий endpoint и формат
запроса. Оценка изначально пустая, тексты адаптируются к типу обращения.
В браузере проверены: выбор оценки стрелками клавиатуры, переключение типа,
ошибка сервера без потери текста, закрытие Escape с возвратом фокуса,
повторное открытие черновика и успешная тестовая отправка с отдельным экраном.
Ошибку/успех проверяли с локальной заглушкой, реальные сообщения не отправлялись.
Проверена форма на localhost и в окне 320×568. На низком экране отступы
и высота поля уменьшены; при ошибке и переполнении доступна прокрутка.
