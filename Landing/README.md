# «Витрина» — статический лендинг

## Готовая публикация

Загрузите **содержимое** папки `dist` в корневую папку сайта на хостинге. Серверу нужны только статические HTML, CSS, JavaScript и WebP-файлы; Node.js, PHP и база данных для отображения лендинга не требуются.

Все пути относительные, поэтому сайт можно разместить и в подпапке домена.

## Прием заявок через Timeweb SMTP

В `dist` уже включён `send-lead.php`. Форма отправляет JSON на `./send-lead.php`, а PHP передает письмо с темой «Новая заявка на тест» через `smtp.timeweb.ru:465` на ящик `hello@calleugene.ru`.

Для работы обработчик должен исполняться PHP 5.6 или новее. Загружайте **содержимое** `dist` в корневую папку сайта, сохраняя `send-lead.php` рядом с `index.html`. Файл `private/smtp-config.php` должен находиться на один уровень выше папки сайта и не быть доступен из интернета. Не переносите SMTP-пароль в `config.js`: этот файл доступен посетителям сайта.

Обработчик принимает `POST` с JSON: `email`, `name`, `museum`, `intent` (`waitlist` или `demo`), `source`, `plan`, `billingPeriod` (`year` или `month`). Пустые необязательные поля не передаются. Успешный ответ выдаётся только после того, как SMTP-сервер принял письмо.

## Локальная работа

```bash
npm install
npm run dev
npm run build
```

`npm run build` пересобирает папку `dist`. Фотографии, шрифты и предоставленные юридические документы включены в сборку. Оригинальные запросы к генератору фотографий сохранены в `image-prompts.json`.
