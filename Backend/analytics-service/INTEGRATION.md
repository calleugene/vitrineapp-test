# Подключение аналитики — 20 октября 2026

Существующий analytics-service доведён до запуска вместе с Visitor и панелью методиста.

## Доступные данные

- Уникальные браузерные посетители, новые посетители, среднее активное время сессии.
- Просмотры экранов, достижение финального экрана, активное время истории, QR/прямые источники.
- Коллекции из сохранённых artifact_visitor_status, без подмены избранным.
- Главная панели: месячная аудитория, посещаемость и недавняя активность посетителей.
- Все запросы страниц «Посетители» и «Статистика» используют выбранный календарный период. Таблица запрашивает отдельную серверную страницу; CSV выгружает текущую страницу.
- Отсутствующие данные не заменяются демонстрационными значениями. Предусмотрены загрузка, ошибки, повтор запроса и пустые результаты.

Уникальный браузер не равен физическому человеку. Авторизация чтения проверяет подписанный токен и актуальность доступа через auth-service. Маршруты, команды, рейтинг и отзывы требуют отдельных источников; они явно недоступны.

## Запуск

На Windows: deploy/windows/Build.ps1, затем deploy/windows/Start.ps1 и deploy/windows/Status.ps1. Analytics слушает 127.0.0.1:18085, Dashboard — 127.0.0.1:18084. Общие пути: /api/analytics и /api/dashboard. Start.ps1 автоматически создаёт vitrine_analytics в существующей установке. Секрет токена берётся из того же runtime config, что у Auth. База аналитики включена в Backup.ps1, сервисы — в Stop.ps1 и watchdog Check.ps1.

При разработке Vite проксирует эти пути на 8085/8084. Для других портов задать VITE_ANALYTICS_DEV_TARGET и VITE_DASHBOARD_DEV_TARGET. Visitor использует /api/analytics/api/v1/analytics/events. Очередь сохраняет исходный ID при повторах, хранит до 100 событий до семи дней, ограничивает запрос десятью секундами и не теряет событие после восьми временных отказов.

## Выполненные проверки

- Analytics и Dashboard: go test ./..., go vet ./..., сборка бинарников.
- Visitor: lint, typecheck, smoke (включая десять отказов 503 и последующую доставку с исходным ID), production build.
- Панель: lint, typecheck, production build, 30 unit tests, включая пустые ответы и различие нуля и недоступной метрики.
- Локальная PostgreSQL: оба readyz через общий прокси возвращают 200.
- Авторизованный HTTP smoke через общий прокси: приём scene_view, повтор с duplicate=true, сохранение в PostgreSQL, visitors summary/dynamics/sources/list, artifacts summary/ranked, dashboard summary/attendance/recent-activity.
- Проверено появление конкретного тестового события в авторизованной выдаче dashboard. Запрос чужого museum_id возвращает 403. Тестовая запись удалена после проверки.

HTTP smoke проверяет серверный путь и реальную PostgreSQL; полноценный сценарий браузера с авторизацией отдельно не подтверждён. Публикация на внешнем хосте не проверялась.
